# VITAL image assets

- `planets/planet-top-right.png` and `planets/planet-bottom-left.png` are the onboarding corner illustrations. Their orientation and transparent margins are part of the artwork.
- `favicon/vital.svg` is the browser tab icon. The reference is set in `html/index.html`.
- `images/sample-space-photo.svg` is a sample page image. Add SVG or JPEG photos to `images/` and reference them from `html/index.html`, for example `../assets/images/photo.jpg`.

The SVGs are image files, so they can be opened and edited independently of the HTML and CSS.
